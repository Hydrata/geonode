# Security Policy

`Hydrata/geonode` is a fork of [`GeoNode/geonode`](https://github.com/GeoNode/geonode). Where to report depends on whose code is affected.

## Vulnerabilities in Hydrata's patches

Anything that only exists in this fork (Hydrata's commits ahead of upstream) goes to Hydrata, privately:

- GitHub: use **Security > Report a vulnerability** on this repository, or
- email [david.kennewell@hydrata.com](mailto:david.kennewell@hydrata.com).

Please do not open a public issue or pull request for a suspected vulnerability.

## Vulnerabilities in upstream code

If the flaw is in code that also exists in `GeoNode/geonode` (check against the upstream branch first), report it to upstream. The upstream process is reproduced below and is unchanged. We will pull the fix into this fork once upstream releases it.

## Supported versions

Only the current `5.x` trunk of this fork receives fixes from Hydrata.

## Reporting a Vulnerability

- **DO NOT** send a security alert on the public mailing list or any other public channel
- **SEND** the report to geonode-psc@lists.osgeo.org and be prapred to collaborate with the GeoNode PSC

Thanks for you support and help!
